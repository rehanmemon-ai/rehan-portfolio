## Build, Verification & Local Preview

Core static site compilation requires only **Python 3.10+ standard library** (`html.escape`, `json`, `pathlib`, `urllib.parse`). Automated CI quality gates additionally use pinned Python QA packages (`.github/requirements-ci.txt`) and Node.js 24 (`package-lock.json`):

```powershell
# 1. Regenerate all 17 HTML routes, sitemap.xml, and robots.txt
python -B build_site.py

# 2. Run structural, SEO, CSS variable, privacy, and anchor verification
python -B check_site.py

# 3. Run unit, escaping, determinism, and regression tests
python -m pytest tests/

# 4. Validate HTML5 syntax using pinned html-validate (Node >=22.22 or >=24.8 required)
npm ci --ignore-scripts
npx --no-install html-validate *.html

# 5. Run pinned Python lint & security scans (.github/requirements-ci.txt)
python -m pip install --no-deps -r .github/requirements-ci.txt
python -m ruff check build_site.py check_site.py tests/
python -m bandit -r build_site.py check_site.py tests/ -ll -q

# 6. Validate JavaScript syntax
node --check site.js
node --check theme-init.js

# 7. Preview locally (loopback only)
python -m http.server 8765 --bind 127.0.0.1
```
